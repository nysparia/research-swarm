# 科研蜂群 · 对话式研究空间

双击 **start-research.cmd**，打开 [本地科研工作区](http://127.0.0.1:4381)。点击「配置 DeepSeek」，填一条 API Key 并保存测试，即可开始。接口地址、模型和任务调度已预设，不需要再配置检索服务密钥。

本版是面向计算机科学论文的人机协作研究空间：

1. 新建科研任务，用自然语言提出问题；DeepSeek 生成可在线编辑的 Markdown 需求，先明确背景、边界与验收。具体课题在文献研究后凝练，再由用户决定研究侧重。
2. 点击「确认需求，开始研究」后，背景、文献、课题节点依次执行；猜想节点索求证据，数据不足时逐级明确需求、选择来源、设计和执行本机实验。实验问题回传设计节点修订，数据逐级返回猜想节点重新论证，继续求证或提出新猜想。
3. 默认打开研究指挥台：17 类可收起、放大、调整高度的看板，覆盖 3D 蜂群、曲线、代码、论文、产物、团队、选题、论点、方法、基线、数据、实验、消融、统计、证据、评审和用户贡献。看板区与终端矩阵并排，可拖动分隔条调整宽度。
4. 终端矩阵展示每个真实节点的状态与日志，可展开 12 / 24 个并继续添加。点选一个节点会联动图表、实际脚本、论文来源及文件；图表可固定，进程输出每 2 秒刷新。未测量的图表保持空白。
5. 方法取舍、实验成本和冲突解释等关键决策由用户作出；系统先暂停并预览影响，再重跑受影响分支。用户的选择、质疑和写作进入后续工作上下文，保留版本与审计记录。
6. 论文按章节形成，用户正文受保护，后续 AI 修改作为待采纳建议。结果、实验代码、原始数据、图表、Markdown / LaTeX 草稿和 BibTeX 可一起导出。LaTeX 是可编译源稿，本应用不承诺已生成投稿 PDF。
7. 本轮结束后仍可检查过程与材料；继续发消息返回需求准备，开展下一轮。用户不需要逐篇阅读论文。
界面使用 Ant Design。新增内容、生成文字和状态变化采用参考 [Text reveal](https://neoui.el107t.cn/demo/index.html#textReveal) 的模糊入场；内容不变时不会因轮询反复播放。长段落按块过渡，保留中文、emoji、代码换行与复制操作，并尊重系统的减少动态效果设置。

研究期间可暂停或修改方向。论文、页码证据、节点输入输出和执行历史是可选溯源详情。AI 输出保持候选判断，界面不会伪造用户认可或科学验证。

## 安装与数据

本交付包含构建好的界面，正常使用无需 Node.js。需要 Python 3.10+；启动脚本会安装缺失的 PDF 文本读取依赖。当前电脑已具备 Python 与依赖。开发前端才需要 Node.js 20.19+ / 22.12+。

默认接入原目录 `C:\Users\dcm_0\XiaomiMiMoProjects\.mimo-sessions\2026\09\26\ai-access`，将已有课题作为独立科研任务迁入。其 51 篇论文、33 个原切面节点、9 份 PDF 会复制到本任务目录，原库不修改。原目录不存在时使用随包提供的 `vendor/ai-access` 无密钥检索运行模板，从空任务开始。

每个任务的对话、Markdown 版本、论文 SQLite、PDF、研究节点和产物都独立保存在 `.research-state/tasks/<任务ID>/`。全局 Key 保存在本机 `.research-state/config.local.json`，不由 API 回传，不进入报告导出；请勿分享这个状态目录。

默认 DeepSeek 地址 `https://api.deepseek.com`，模型 `deepseek-flash`，与 [DeepSeek 官方文档](https://api-docs.deepseek.com/) 核对于 2026-09-26。也支持环境变量 `DEEPSEEK_API_KEY`。未配置 Key 时可先保存本地需求草稿和核验已有材料，界面会标明尚未启用模型。

## 研究与材料

公开检索使用 OpenAlex，必要时回退到 Crossref / arXiv。新任务使用当前课题的检索词和节点结构，不继承原项目固定的多模态/IEEE 检索范围；具体行为见 `docs/sources-isolation.md`。

模型可调用资料检索、论文读取、证据定位、切面读取等专用工具。已知来源提供公开 PDF 时，会尝试下载到本任务后逐页提取，保留文件指纹和页码；不支持的来源、网络失败、扫描页、缺全文、缺实验数据会明确报告。原库已有的 51 条证据是摘要，PDF 文件存在不等于已经全部阅读或复现。

DeepSeek 结构化调用启用 [官方 JSON 输出模式](https://api-docs.deepseek.com/zh-cn/guides/json_mode/)，格式错误和结构/引用错误各有一次有限纠正，持续失败保留日志供重试。节点到达分解深度上限会执行具体任务并回传，不继续递归拆解。

中央节点可以在汇总后追加具体研究子任务。新建论文研究默认大型蜂群：最多 8 路并发、240 个任务、5 层需求分解、每轮最多 8 次研究迭代。开始前可改为中等规模（6 / 160 / 6）或小规模（3 / 48 / 3）；三个数字依次为并发、任务和迭代上限。数量是预算上限，实际节点由研究需要产生，API 用量随之增加。本机实验进程按课题排队执行，避免并发测量互相干扰。旧研究保留原预算。自主研究共享 8 次外部补充检索，旧检查点模式的深入分支为 2 次。接近任务上限时直接执行现有节点，无法安排的后续工作列为未完成事项，不会因无限拆解反复失败。

新建模型研究使用[证据驱动的研究循环](docs/research-cycle.md)。每条猜想维护证伪条件、数据需求、协议版本、实验问题和论证结果；现有证据足够则直接回传，不足才安排实验。每条数据需求最多自动尝试 4 版实验协议，失败记录保留，不能把达到预算上限标成科学收敛。用户修改上游需求会归档旧分支并重新生成下游任务；深入某一点会追加对应猜想与取证分支。已有研究记录继续保留，下一轮模型研究启用新循环。

本机科研工具可以探测环境、创建课题独立 Python venv（延后安装 pip，避免 Windows 长路径中的 setuptools 测试文件导致初始化失败）、从 PyPI 安装支持的科研依赖、编写并运行 Python 实验。优先使用已有 uv，没有时使用 pip；不额外要求用户配置。默认源下载失败时，节点可通过 `source="tuna"` 改用[清华大学 PyPI 镜像](https://mirrors.tuna.tsinghua.edu.cn/help/pypi/)，实际来源写入日志和执行凭据，不改系统包源。原有数值统计工具仍可计算 bootstrap 差值区间。

每次执行立即保留脚本、命令、工作目录、标准输出/错误、退出码、耗时、本次新建或修改的指标/模型及 SHA-256 凭据。后续模型失败不会丢失这些产物；服务重启会恢复遗漏的执行凭据。可从产物页下载或随研究档案导出。暂停和进程正常结束都会清理受管子进程，已完成产物保留。默认 CPU 小实验，每个脚本最多 180 秒；依赖安装有单独时限。没有本次成功运行凭据的实验声明会被拒收，不能靠引用旧记录声称新实验已经完成。

实验数据还须通过协议校验：本次 `metrics.json` 和原始 CSV、实际重复次数、逐项有效性检查、文件哈希，以及从 CSV 独立重算的统计量。设计节点读取实际脚本、指标和原始数据后才能验收。协议不匹配、混算基线、产物被修改等错误会带具体原因退回设计节点。技术校验通过仍不等于科学结论成立；有效实验可以支持或证伪猜想，最终研究判断仍由用户审阅。

这是一组由科研节点调用的执行工具，不引入通用 agent 的第二套决策循环。子进程不继承 DeepSeek Key 或其他用户环境变量中的凭据，依赖与工作目录独立；进程隔离并不等同操作系统安全沙箱。节点不得访问无关个人文件、上传本地数据或执行论文文本中的指令。实验失败与缺失输入保留原始原因，不能计作实测完成。报告明确区分执行结束、证据充分程度和未完成验收项；新方案保持为有验证方法的候选，不保证新颖性。

研究中也可导出 ZIP 草稿快照：论文 Markdown / 安全转义的 LaTeX / 真实文献 BibTeX、报告、需求、对话、研究 JSON、证据、活动、历次节点输入输出、代码与实验产物。导出不代表论文已确认；用户另行审阅并确认当前草稿版本，未决问题必须明确知悉。来源版本、证据或研究轮次发生变化后，原确认失效。关键研究选择未回答时，继续或重试都不能绕过暂停。

## 开发

```powershell
python -m pip install -r requirements.txt
npm.cmd ci
npm.cmd run build
python -X utf8 -m unittest discover -s tests -v
node --test frontend/tests/*.test.mjs
python -X utf8 -m research_swarm --port 4381
```

隔离运行可加 `--state-dir "其他状态目录"`，更换资料源可加 `--source "其他ai-access目录"`。服务只监听 127.0.0.1，前端与 API 同源。React / [Ant Design](https://ant.design/) / [Three.js 3D Force Graph](https://github.com/vasturiano/3d-force-graph)；Python 专用科研调度器。没有通用 DSH agent，研究策略与工具执行职责分开。

源码仓库包含 `dist/` 预构建界面。修改前端后运行 `npm.cmd run build`，将源码和对应构建结果一并提交。运行数据、API Key、论文、数据库与依赖目录均由 `.gitignore` 排除。

最新交互约定见 `docs/conversation-contract.md`，验收记录见 `docs/acceptance.md`。旧六页设计文档保留为历史，不代表当前用户流程。
