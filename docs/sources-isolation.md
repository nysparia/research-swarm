# 每个科研任务的独立检索库

`prepare_source(original, destination, task_id, title, description, import_existing=False)` 返回本任务的独立原检索程序目录，可直接传入 `Library`。首次创建采用同目录暂存后改名；已有目录必须带匹配的管理清单，禁止覆盖其他目录或其他任务。重复调用仅更新当前题目、描述、关键词和检索根，保留论文、证据、PDF 及之后自行配置的模型信息。

新任务默认没有论文和证据，有本课题自己的检索根。配置中只有本任务的 topic，数据位于 `tasks/<task_id>/data/paper_research.sqlite`。原始项目代码和数据库只读，不在其中运行初始化或检索。

迁入任务使用 SQLite 只读备份，保留论文、证据、事实、评分依据和历史结构 ID。只复制 `Library` 校验过的 PDF，并将副本的 `PDFPath` 改为任务自己的文件；无法验证的旧路径置空。历史评分和分类是迁入资料，不会被伪装成新任务的模型研究。

仅复制固定名单中的 Python 运行文件。不会复制 `.env`、日志、模型密钥、原模型供应商配置、`node_modules` 或其他任务的数据。目的地最初的模型配置为空；公开检索不使用模型 API key。论文源自己的可选 Key 由上层工作区运行设置或专用环境变量提供，不从原项目复制，不进入检索记录或报告。

正常工作区任务由宿主 `research_swarm/retrieval.py` 执行多源检索，`retrieval_store.py` 将候选、各源元数据、发现路径和真实引用关系写入独立数据库。已存在的受管任务也直接使用当前宿主实现，无需重新复制数据。候选池上限与模型阅读列表上限独立；仅对确实带有匹配归属清单的任务采用这一实现。详见 [多源论文检索](literature-search.md)。

复制的旧 CLI 与 `swarm_task_scope.py` 保留兼容用途：节点来自当前课题关键词；启发式评分带未核验说明；OpenAlex 不限定 IEEE，稀疏时回退 Crossref / arXiv，`top_k` 限制入库且默认不自动下载 PDF。直接调用无管理清单的旧资料目录仍走原 CLI；其行为不等同于工作区的新多源检索。

这些适配只负责公开资料检索和透明规则整理，不等于模型科研或复现实验。公共接口可能限流、不可用或缺少摘要；没有摘要的论文不生成摘要证据。关键词匹配不等于语义相关性判断，后续分析与切面细化由工作区的模型执行。来源错误、预算停止和部分结果均显式记录；某个源失败不会丢弃其他来源已取得的论文。
